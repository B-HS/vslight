VSLight is a native macOS 27 volume controller built with SwiftUI, CoreAudio, and Carbon global shortcuts.

## Highlights

- Precise system volume with a slider and click-to-edit percentage.
- Presets with global shortcuts. No default presets.
- Output device switching from the menu bar window.
- Liquid Glass UI, macOS 27 `reorderable()`, and Swift 6 strict concurrency.
- Sleep/wake, session, CoreAudio restart, and device-change recovery.
- Launch at login with approval state and restart controls.
- Korean, English, and Japanese UI.
- Per-app volume through the bundled HAL audio driver (experimental).

## Installation

1. Download `VSLight-0.1.0.zip`.
2. Move `VSLight.app` to `/Applications`.
3. Open the app. The build is Developer ID signed and notarized.
4. Optional: open `Settings > Per-App Volume` and click `Install Driver`.

The per-app driver requires an administrator password and restarts `coreaudiod`. It is not App Store compatible and adds one IO buffer of routing latency. The app must stay running while per-app volume is enabled.
