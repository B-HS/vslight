VSLight v0.1.5 completes the volume percentage field fix from v0.1.3.

## Fixes

- Clicking anywhere outside the percentage field now ends editing and shows the current volume.
- A typed value is applied only with Return. In v0.1.3 it was also applied when the field lost focus; now leaving the field without pressing Return discards it.
- No audio driver changes. The v0.1.1 driver remains compatible, so upgrading the app does not require reinstalling the driver.

## Installation

1. Download `VSLight-0.1.5.zip`.
2. Move `VSLight.app` to `/Applications`.
3. Open the app.

If you already installed the v0.1.1 driver, keep it. Reinstall the driver only if the app reports that it is missing.

## Requirements

- macOS 27.0 or later
