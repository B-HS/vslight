VSLight v0.1.1 is a patch release for the published v0.1.0.

## Fixes

- Fixed a crash when enabling per-app volume. The CoreAudio I/O blocks are now nonisolated and no longer assert MainActor isolation on the realtime audio thread.
- The monitor output volume is no longer forced to 100% when per-app volume starts. The existing output volume is preserved.
- Enabling and disabling per-app volume now returns the system to the original output device without changing its volume.

## Installation

1. Download `VSLight-0.1.1.zip`.
2. Move `VSLight.app` to `/Applications`.
3. Open the app.

The HAL driver is unchanged from v0.1.0. If it is already installed, no driver reinstall is required.

## Requirements

- macOS 27.0 or later
