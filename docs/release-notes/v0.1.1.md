VSLight v0.1.1 is a patch release for v0.1.0.

## Fixes

- Per-app volume now produces audio. The HAL driver exposes a separate input-only device, and the app reads it while the main virtual device remains the default output.
- Fixed distorted per-app audio by matching the driver streams to 48 kHz, 32-bit float, stereo and clearing the scratch mix buffer on every cycle.
- Fixed a stale FIFO read cursor that could leave per-app playback silent until the driver restarted.
- Fixed a crash when enabling per-app volume. CoreAudio I/O blocks are now nonisolated and no longer assert MainActor isolation on the realtime audio thread.
- The monitor output volume and mute state are saved before enabling and restored exactly when disabling. The monitor output is never forced to 100%.
- Enabling and disabling per-app volume now reliably returns the system to the original output device.

## Installation

1. Download `VSLight-0.1.1.zip`.
2. Move `VSLight.app` to `/Applications`.
3. Open the app.

The HAL driver changed in this release. Reinstall it from `Settings > Per-App Volume` (Remove Driver, then Install Driver) or run `sudo ./Scripts/install-driver.sh` from a source checkout.

macOS asks for microphone access when per-app volume first reads the virtual driver input. Allow it for per-app volume to work.
