VSLight v0.1.1 is a patch release for v0.1.0.

## Fixes

- Fixed a crash when enabling per-app volume. CoreAudio I/O blocks are now nonisolated and no longer assert MainActor isolation on the realtime audio thread.
- Fixed silence when enabling per-app volume. The HAL driver now delivers mixed audio through a FIFO read buffer instead of matching absolute IO timestamps.
- The monitor output volume is no longer forced to 100% when per-app volume starts.
- The monitor output volume and mute state are saved before enabling and restored exactly when disabling. No fixed volume is used.
- Enabling and disabling per-app volume now reliably returns the system to the original output device.

## Installation

1. Download `VSLight-0.1.1.zip`.
2. Move `VSLight.app` to `/Applications`.
3. Open the app.

The HAL driver changed in this release. Reinstall it from `Settings > Per-App Volume` (Remove Driver, then Install Driver) or run `sudo ./Scripts/install-driver.sh` from a source checkout.
