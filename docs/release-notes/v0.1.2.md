VSLight v0.1.2 adds visible progress for HAL driver installation and removal.

## Changes

- Driver installation and removal now show a six-step checklist in Korean, English, and Japanese.
- The app waits for the coreaudiod restart, then verifies the driver once and retries once if needed instead of querying CoreAudio continuously during the restart.
- Driver detection now requires both the output and input devices, preventing a partially installed old driver from being treated as ready.
- No audio processing changes. The v0.1.1 driver remains compatible, so upgrading the app does not require reinstalling the driver.

## Installation

1. Download `VSLight-0.1.2.zip`.
2. Move `VSLight.app` to `/Applications`.
3. Open the app.

If you already installed the v0.1.1 driver, keep it. Reinstall the driver only if the app reports that it is missing.
