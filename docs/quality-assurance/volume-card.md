## 수동: 메뉴 막대 팝오버

자동 검사는 일반 창에 뷰를 띄운다. `MenuBarExtra` 창에서는 아래를 직접 확인한다.

- [ ] 숫자를 클릭한 뒤 슬라이더를 움직이면 숫자가 바로 따라오고 입력란 배경이 사라진다.
- [ ] 숫자를 입력하고 Return을 누르면 볼륨이 적용되고 입력란 배경이 사라진다.
- [ ] 숫자를 클릭한 뒤 프리셋이나 키보드 볼륨 키로 볼륨을 바꾸면 숫자가 바로 따라온다.
- [ ] 슬라이더를 움직인 뒤 팝오버를 닫았다 열어도 볼륨이 그대로다.

## 테스트 부채
