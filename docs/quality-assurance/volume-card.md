## 수동: 실제 앱

자동 검사는 가짜 모델을 쓴다. CoreAudio 가 연결된 실제 앱에서는 아래를 직접 확인한다. 확인 전에 실행 중인 VSLight 가 확인하려는 빌드인지 `ps -axo pid,lstart,command | grep VSLight.app` 로 본다.

- [ ] 숫자를 클릭한 뒤 슬라이더를 드래그하면 숫자가 바로 따라오고 입력란 배경이 사라진다.
- [ ] 숫자를 입력하고 Return을 누르면 볼륨이 적용되고 입력란 배경이 사라진다.
- [ ] 숫자를 클릭한 뒤 팝오버의 빈 곳을 클릭하면 입력란 배경이 사라지고 현재 볼륨이 표시된다.
- [ ] 숫자를 클릭한 뒤 키보드 볼륨 키로 볼륨을 바꾸면 숫자가 바로 따라온다.

## 테스트 부채

- 실제 드래그와 CoreAudio 되읽기: 스크립트는 한 지점 클릭과 가짜 되읽기로 대신한다. 남은 위험은 드래그 도중 연속 변경에서만 나타나는 차이다. 팝오버 안에서 드래그를 자동화할 필요가 생기면 추가한다.
